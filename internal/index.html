one system, many surfaces

The work is complex.
The experience isn’t.

Every capability in the product is designed around the same unit of work: a customer conversation. That makes the story understandable to a customer — and legible to an engineering recruiter.

◎

Unified inbox

Email, live chat and WhatsApp conversations come together with teams, tags, statuses, custom attributes, search and snoozing.

CONVERSATIONS
✦

AI assistance

Knowledge-aware assistance can answer live-chat questions, hand off to agents, draft replies, summarize conversations and surface answers.

AI + KNOWLEDGE
⌁

Automation engine

Rules can route and update conversations, while macros and auto-assignment turn repetitive support work into predictable workflows.

WORKFLOWS
◷

SLA + analytics

Response targets, breach notifications, CSAT and reporting make operational performance visible instead of anecdotal.

OPERATIONS
⌘

Admin + security

Roles, granular permissions, OIDC/SSO, activity logs, notification settings and business-hours controls are built into the platform.

GOVERNANCE
↗

Integrations

APIs, webhooks and context links make LibreDesk composable with the rest of an organization’s systems and workflows.

stack snapshot

Built as a real application, not a landing-page prototype.

The uploaded repository contains a Go backend and a Vue 3 frontend. The application uses PostgreSQL and Redis, has realtime WebSocket paths, frontend component tests/e2e coverage, and a broad internal domain model for conversations, AI, automation, auth, reporting and integrations.

BACKENDGo 1.25 · HTTP handlers · domain packages
FRONTENDVue 3 · Vue Router · Pinia · Tailwind / component UI
